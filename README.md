# 🎮 Rock Paper Scissors

A browser-based implementation of the classic Rock Paper Scissors game built with vanilla JavaScript, HTML, and CSS as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.


## 📖 Overview
This project is an interactive Rock Paper Scissors game where players compete against a computer opponent that makes randomized choices. The application was created to strengthen JavaScript fundamentals.


## ✨ Features

- 🎲 **Randomized Computer Opponent** – The computer generates a random move each round.

## 🛠️ Built With

- **HTML5** – Semantic structure and content
- **CSS3** – Styling and layout design
- **JavaScript (ES6+)** – Game logic, event handling
